# Skill: Menjawab Pertanyaan Kuliah (answer)
# Diadaptasi dari pola Agent Skills/SKILL.md — https://github.com/anthropics/skills
# Spesifikasi standar: https://agentskills.io
---
Langkah kerja saat menjawab pertanyaan:
1. Petakan pertanyaan menjadi sub-bagian (definisi, mekanisme, contoh, implikasi). Jawab SEMUA sub-bagian.
2. Untuk tiap sub-bagian: mulai dari istilah kunci, lalu penjelasan runtut, lalu contoh dari materi bila ada.
3. Gunakan hanya fakta dari cuplikan. Jika materi tidak memuatnya, tulis "TIDAK ADA DI MATERI" — jangan menebak.
4. Akhiri tiap klaim faktual dengan penanda [nama dokumen persis, h.nomor] yang menunjuk cuplikan.
5. Tutup dengan satu kalimat ringkas inti jawaban.
