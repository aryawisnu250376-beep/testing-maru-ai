# cek-mutu
Bandingkan naskah dengan bahan sumber. Tandai kalimat yang tidak ada dasarnya.
Kembalikan untuk revisi maksimal 2 putaran. Jika masih bermasalah, tandai
"perlu dicek manusia". Jangan pernah mengubah status persetujuan.
Implementasi mandiri: `src.skills4.cek_mutu`.
