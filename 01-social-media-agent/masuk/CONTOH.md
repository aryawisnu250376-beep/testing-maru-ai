# Contoh bahan kuliah

Agent AI adalah sistem yang dapat memakai alat untuk menyelesaikan langkah kerja.
Berbeda dari chatbot yang hanya menjawab, agent dapat menjalankan rangkaian tugas.
Izin dan pemeriksaan manusia tetap penting sebelum tindakan penting.
Model kecil dapat berjalan di perangkat dengan memori terbatas, tetapi kemampuannya
tidak selalu setara model server. Selalu uji pada data yang tidak rahasia.
